- **Scope**:
  - A table maps each key-read **site** to a kind named as in `kinds.tsv`. A shared reader site, such as the Y/N questions or the menu reader, is told apart by the caller frame that the original pushed, never by the text. Each entry cites its routine in the named listings and the record that shows it.
  - Each entry also lists the keys the screen accepts, from `catalogue.tsv` (its `screen` and `owner` rows), with each key's code as 08DD returns it.
  - `KeyWait.kind` is the kind. A site with no entry raises `UnknownScreen(site, text)`; the runner never guesses.
  - Where a screen has a cursor or a selection, its `view` reads it from memory: the menu item, the country browsed, the player selected. Other state views come with the screen task that needs them (G10–G14).
  - The kinds the core cannot reach yet are listed in `docs/core.md` with the reason. Interrupts and type-ahead are not served (T100).
