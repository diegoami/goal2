# T06 The state adapter: round-trip the original's savestate through goal2's state representation

- **Kind**: slice
- **Issue**: #<new>
  **Branch**: `task/T06-state-adapter` · **Merge after**: T05
- **Implementer**: the main session
- **Reviewer**: `luna` (the adapter is a thin layer over the vendored readers; the lighter reviewer fits)
- **Evidence**: E006-r0001 (the main-screen savestate). The state layout is the original's memory image (DS:A917 for the country records, DS:A91B for the player records, DS:7B62 and DS:8336 for the RNG words). The vendored `Savestate` and `players` readers (T01) already parse the layout; the adapter wraps them.
- **Owns**: `goal2/engine/state.py` (the state adapter: `from_savestate`, `to_savestate`, round-trip), `goal2/tests/test_state.py` (the round-trip test against E006-r0001).
- **Scope**:
  1. The state adapter: `from_savestate(state_bytes) -> GameState` extracts goal2's state from a savestate. `to_savestate(game_state) -> bytes` writes it back. The round-trip test loads E006-r0001, calls `from_savestate`, then `to_savestate`, and asserts every byte matches the original.
  2. The state model: `GameState` holds the 3061-record player array (from T03), the 128 country records (from T02), the 20 managed-country player numbers, the RNG words (DS:7B62, DS:8336), and the match state (score, minute, half). The adapter reads/writes these through the vendored `Savestate` and `players` readers.
  3. The round-trip test: downloads E006-r0001, calls `from_savestate`, then `to_savestate`, and compares the output bytes with the original. The test skips with the reason when the fetch fails.
- **Done when**:
  1. `python3 -m unittest goal2.tests.test_state` is green (skipped with the reason when the fixture is absent).
  2. The round-trip test: `from_savestate(E006) -> to_savestate() == E006` byte-for-byte.
  3. `python3 -c "from goal2.game import state; s = state.from_savestate(open('.cache/e006-r0001-main.sav','rb').read()); print(s.players[1][:6].hex())"` prints the first 6 bytes of country 1's first player (01 + 5 LCG-driven bytes).
- **Hazards**:
  - the savestate is 223,095 bytes; the round-trip must match every byte, not just the fields the adapter knows about (unused fields must be preserved);
  - the vendored `Savestate` class reads VGA and Memory components separately; the adapter must preserve both, not just the Memory component;
  - the adapter must not commit a savestate (rule 19); the test reads from `.cache/`, which is git-ignored.
