- **Scope**: The ZIP has a second launcher, `goal2-new.cmd`, which starts the new window (`goal2.ui`) with the same
  environment as `goal2.cmd`: the bundled PyPy for the engine process, `PYTHONSAFEPATH`, and no outside Python
  variables. `goal2.cmd` is unchanged, and stays the default the docs name. The task protects one claim: **the new
  window starts from the unpacked ZIP on a machine with no Python, and plays a match on the bundled PyPy.**
  1. `goal2_launch.py` takes the module to run from the launcher (a `--window new` argument or a second small
     script), with no duplicated environment code.
  2. `goal2-new.cmd` is in `LAUNCHER`, in the record, and in the ZIP.
  3. **The smoke** (the package workflow, hosted Windows runner) adds:
     - `goal2-new.cmd --help` exits 0;
     - the new window starts offscreen from the unpacked ZIP, imports a stand-in data folder through S01, and
       shows S02. The workflow's `.cache/` gives it GOAL.DAT and the template, outside the zipped folder.
  4. `docs/packaging.md` names both launchers, and says which one is the default and why (§6 item 17).

  2. The package workflow on the PR is green, including the new smoke steps. The PR links the run and its
