- **Kind**: slice
- **Issue**: — (tracked in this file until issues are used) · **Branch**: `task/T01-skeleton` ·
  **Merge after**: — (first task)
- **Implementer**: the main session (goal2 runs thin-process until it has surface for the harness)
- **Evidence**: goal2-archaeology at `8760df9` (T24's merge):
  - `runtime/model/quick_engine.py` — the quick engine, seed-exact on all ten E010 records
    (`check_model.py` `match: 10/10`); its input is the game's memory at the half-time stall of a
    quick result; F012 (`findings/F012-quick-engine-rule.md`) is its rule, contest by contest.
  - The E010 records (`runs/E010/E010-r0001..r0010.json`) and their published half-time states on
    GitHub release E010 of goal2-archaeology — the fidelity oracle.
  - F005 (quick ≠ watched engine), F004/F006 (the RNG, determinism), F012 — everything this seam
    claims is `[confirmed]` by these; the CLI's shape is `[designed]`.
- **Owns**: the whole tree (first task)
- **Scope**:
  1. The package skeleton: `goal2/__init__.py`, `goal2/engine/` (vendored only),
     `goal2/cli.py`, `goal2/tests/`, `tests/` link or layout as decided by the implementer,
     `tools/check_provenance.py`.
  2. Vendor `quick_engine.py` (and the minimal savestate reader it needs, if any — prefer a thin
     loader citing goal2-archaeology's `runtime/driver/savestate.py` layout notes) into
     `goal2/engine/`, byte-identical, with `PROVENANCE.md` rows (source repo, commit `8760df9`,
     findings F012/F004/F006).
  3. The CLI: `python -m goal2.play <savestate>` loads a half-time state, runs the vendored model,
     and prints the final score, the second half's goal minutes and scorers, and both seed words —
     the same output `check_model.py` compares. It refuses (with a message) what the model's
     docstring refuses: the foul path beyond `278A`, extra time, penalties — no invented behaviour.
  4. The fidelity test: fetch one E010 record's published half-time state into `.cache/`
     (git-ignored; never committed) and assert the seam reproduces the record's outcome exactly
     (score, goals, seeds); skip with the reason when the state is absent. Plus unit tests for the
     loader and the CLI's refusal paths (each fails before the behaviour exists).
  5. `tools/check_provenance.py`: exits 0 when every file under `goal2/engine/` has a PROVENANCE
     row whose source commit exists in goal2-archaeology (path from `GOAL2_ARCHAEOLOGY` or the
     default sibling checkout), non-zero otherwise.
  Out of scope: the bot, any watched-engine behaviour, competitions, UI, the country/squad data
  model (later tasks vendor those with their own provenance rows).
- **Done when**:
  1. `python3 -m unittest discover` is green, including the fidelity test against E010-r0001's
     published state (skipped with its reason when `.cache/` has no state).
  2. `python3 -m goal2.play <path to E010-r0001's half-time state>` prints r0001's recorded score,
     goal minutes and both seed words exactly; the PR's fenced block shows it.
  3. `python3 tools/check_provenance.py` exits 0; `grep -RniE '\[(confirmed|derived|designed)\]'`
     over new non-vendored files shows every behaviour claim tagged.
- **Hazards**:
  - never commit a savestate or any GOAL2 asset (CLAUDE.md rule 3; the state fetch goes to
    `.cache/`, git-ignored);
  - never edit the vendored file, not even an import (a needed change is a thin wrapper in
    `goal2/`, and a defect goes upstream);
  - the model is deterministic from its input state: no wall clock, no unseeded randomness anywhere
    in the seam;
  - a fidelity test that has never failed proves nothing: show the seam failing (or the test
    red) before the loader/CLI wiring is complete.
