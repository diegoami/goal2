# T112 Convert original and core saved games

- **Kind**: feature (separate from the 0.1 playable chain).
- **Issue**: [#341](https://github.com/diegoami/goal2/issues/341) · **Branch**: `task/T112-save-formats` · **Merge after**: T100, T106.
- **Evidence**: [confirmed: goal2-archaeology F001 at 53d7ef5] The original writes named `.GL` saves. [derived: T100/F029] A `.g2core` checkpoint also contains suspended execution state. [designed: owner, 2026-10-23] G13 keeps existing desktop `.g2core` save/resume; schedule conversion between the two formats separately. Establish the actual original save/load record layout and supported boundaries from evidence before implementation; request missing traces under CLAUDE.md §15.
- **Owns**: new `goal2/core/save_formats.py`, necessary core file-I/O adapters, `tools/convert_save.py`, `goal2/tests/test_core_save_formats_t112.py`, SLOW_PATHS and save-format/user documentation. Vendored engine files remain untouched.
- **Scope**: Import an original `.GL` into a resumable core checkpoint and export a supported core checkpoint to an original-loadable `.GL`. Expose explicit commands and format detection. Define which original save boundaries are representable; refuse other states with a useful explanation. Preserve representable career facts and document execution/RNG state the original format cannot retain. Keep G13's desktop save flow on `.g2core`; conversions are opt-in and never overwrite their input.
- **Done when**:
  1. `GOAL2_SLOW=1 python3 -m unittest goal2.tests.test_core_save_formats_t112 -v` checks genuine private saves in both directions: imported career facts versus the original's load, and exported files loaded by the original and followed through recorded original keys. It measures RNG/continuation behavior explicitly and tests malformed files, unsupported boundaries and input preservation. Main has no converter. No test fabricates guest state by memory writes.
  2. Documented CLI commands convert both ways, report their limits, and preserve the source file; private fixture hashes/provenance are committed, original bytes are not.
  3. Full pre-merge validation at the exact head and native Windows pass.
- **Review**: independent saves/fidelity review through `tools/review_pr.sh`.
- **Hazards**: A suspended CPU checkpoint may contain facts `.GL` never stores. Never call a lossy conversion lossless, manufacture missing memory, or publish an original-containing fixture.
