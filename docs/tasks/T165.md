- **Owns**:
  - New `goal2/ui/` modules for S08, S09 and S10, and the card drawing they share.
  - `goal2/tests/test_ui_squad_t165.py`, `docs/ui.md` (its own section).

- **Scope**: The squad, pool and tactics screens, built as screens on T162's base, each taking an open
  `DesktopModel`. The task protects one claim: **every change made on these screens is the change the model makes
  for the same request**: the same exchange, position, club position, tactics and name, read back through
  `DesktopModel.view`.
  1. **S08 Squad and pool.**
     - The player card with every field today's card shows, in the mockup's layout; the twenty or the pool on the
       right (←→).
     - The original's two-Enter exchange: Enter on a pool player, ← back, Enter on the player he replaces. The
       Enter hint reads *put here* once a pool player is picked.
     - **Ins** the assistant's 20 (today's *Suggest*), shown before it is applied, with Enter to accept and Esc to
       keep.
     - **R** / **Shift+R** position, **C** club position, **T** to S09, **F2** new name, **Esc** back.
  2. **S09 Player tactics.** The five lines with their values and **P** on a line set for this player; arrows choose
     the line, Enter alters it, Esc returns to the card.
  3. **S10 Team tactics.** The eight lines, each with its value now and the other option; ↑↓ choose, Enter changes,
     Esc returns.
  4. Mouse equals key on every screen.
- **Done when**:
  1. `python3 -m unittest goal2.tests.test_ui_squad_t165 -v` passes offscreen, and fails on `main`. On a career
     from `DesktopModel.open` (skipping like the existing desktop tests when `.cache/` lacks the files), it shows:
     - **Exchange:** a pool player put in place of a squad player by the two-Enter exchange gives the same `view()`
       as `model.exchange` with the same pair. The *put here* hint shows between the two Enters.
     - **The assistant's 20:** Ins then Enter gives the assistant's 20; Ins then Esc changes nothing.
     - **Position, club position, name:** R, Shift+R, C and F2 (with a name typed) each equal the model's own
       change for the same player.
     - **Player tactics:** each of S09's five lines, altered once, equals the same tactics change through the model,
       and **P** marks it.
     - **Team tactics:** each of S10's eight lines changed once equals the model's change.
     - **Mouse:** a click on a row and on a bar key does what its key does.
  2. `QT_QPA_PLATFORM=offscreen python3 -m goal2.ui --screenshot <dir>` (or a tool under `tools/` if `__main__` is
     T163's at that moment) writes S08 (squad and pool, with *put here*), S09 and S10. The PR shows them next to
     the mockups.
  3. Existing tests are unchanged and pass.
  4. `python3 tools/check_premerge.py --expected-head <sha>` passes; Windows and Linux green, except
     `test_core_replay_t140` (#520).
