- **Scope**:
  - Two pure functions in `goal2/ai/cpu.py`:
    - `pick_computer_eleven(player_records: list[bytes], squad_indices: list[int]) -> list[int]`
      - Returns the top 11 of `squad_indices` by the player record's ability byte at `+1` (ties broken by squad order — the lower squad index wins).
      - The returned list is sorted by descending ability, then ascending squad index.
      - `len(squad_indices) < 11`: raise `ValueError` ("country must have at least 11 squad members"). The country always does (T02 confirms 20 squad records per country).
    - `get_computer_tactics(country_record: bytes) -> int`
      - Returns the byte at `country_record[0x2D]` (`0..7` of the byte; `0x2D` ≤ `0xBF`).
      - The country record is 0xBF bytes; the byte at offset 0x2D is one of the 8 tactics bits per F010.
  - Both functions are pure: they take data and return data, no state mutation. The main loop (a future task) will call them and write the results into `GameState`.
  - Out of scope: per-position picking (Q035) — T15 ships "top 11 by ability, ignoring formation"; the change-tactics-when-behind loop (A-CPU-2's full behaviour) — T15 ships only the read side. Both are follow-up tasks once Q035 lands.

- **Hazards**:
  - "Test passes with the grid deleted" (lesson from T05/T09/T10/T11/T12/T13/T14 review rounds): the expected eleven list is computed from sorting the input abilities, not a hardcoded literal — so deleting the sort fails the test.
  - "Ability byte is at the wrong offset" — the test asserts the function reads `record[1]` (the ability byte at `+1`), not `record[0]` (the surname byte) or `record[6]` (the position byte). Mutation: change the offset; the test fails because the abilities would be `[0, 0, ...]` (the surname bytes).
  - "Tie-break by squad order" — when two players have the same ability, the lower squad index (earlier in the squad list) comes first. The Done-when 2 input has two players with the same ability at positions 19 and 20 (both 11); the lower index (19) wins. Mutation: sort only by ability (stable=False); the test fails because player 20 would come first.
  - "Country record length is wrong" — the function takes a `bytes` of any length ≥ `0x2E`. The test uses `b'\\x00' * 0x2D + b'\\x8B' + b'\\x00' * <rest>`; passing a shorter buffer raises `IndexError` (the test asserts `get_computer_tactics(b'')` raises).
  - "AI mutates state" — T15 is pure functions; no `GameState` field is added. Verify by running the full test suite — any failure there is a T15 regression.
