  offscreen at factor 2; `measurements/T144/native_probe.py` (T144) needs real windows, focus and
  pixels. [designed: owner, 2026-10-29] native scaling checks move to CI.
- **Owns**: the native jobs in the two workflows, `goal2/tests/test_ci_workflows_t148.py`,
  `measurements/T148/**`.
- **Scope**: Linux job: Xvfb with a real window manager (xfwm4), isolated D-Bus/XDG, Qt xcb; Windows
  job: the hosted desktop. Each runs the native probe at Qt factors 1 and 2 in separate processes,
  rejecting offscreen backends, and uploads its receipts (backend, focus, on-screen geometry,
  pixel and save-equality results, source hashes) and screenshots. Offscreen evidence stays labelled
  offscreen; this does not replace the owner's physical-display playtest.
- **Done when**:
  1. `python3 -m unittest goal2.tests.test_ci_workflows_t148 -v` fails before and passes after (jobs
     present, offscreen not set, factor 1 and 2 separate, receipts uploaded through the refusal filter).
  2. Green Linux and Windows native runs whose receipts report the native backend and active focus.
  3. `python3 tools/check_premerge.py --expected-head <sha>` passes.
- **Review**: none.
- **Hazards**: bare Xvfb without a window manager (no real focus); a factor-2 window larger than the
  virtual screen (clamped); uploading a capture of an original screen.
