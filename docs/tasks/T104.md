# T104 T102 review follow-ups, and the core tests as slow tests

- **Kind**: fix (bug #316; corrections of T102, and of T103's test cost)
- **Issue**: #316 · **Branch**: `task/T104-review-followups` locally (a cloud session uses its own branch) · **Merge after**: T103
- **Evidence**:
  - [derived: the independent review of #314, https://github.com/diegoami/goal2/pull/314#issuecomment-6346075899, findings R1, R2, R3 and R5] The review found these defects:
    - **R1.** At the `substitution` stoppage after a pause, Esc sends `answer([])`. The kit's `_on_notice` (`goal2/engine/original_match/match.py`) answers that with the swaps that were asked for, so they are still made. Yet `docs/desktop-management.md` says Esc "drops the choice", and nothing reports the swaps.
    - **R2.** `watched_match._report` infers a refusal; its tag says `[confirmed]`. The fallback text 'not made by the original' is untagged.
    - **R3.** `WatchedJobs._pause_pending` is cleared only by a `pause` decision, so an Enter that is dropped leaves every later Enter ignored. `start(bench=True, frames=False)` can never pause.
    - **R5.** `test_watched_jobs.test_start_failures_clear_publication_and_allow_restart` calls `cancel()` once (a 0.5 s join) and timed out under `check_premerge` load.
  - [derived: PR #317's report] `goal2.tests.test_core_screens_t103` plays a whole watched match (8–11 min), and T100's module takes about 3.5 min. Neither is a slow test, so every pre-merge run and every Windows run pays for them.
- **Owns**:
  - `goal2/desktop/bench_page.py`, `goal2/game/watched_match.py` (`_report` only), `goal2/game/watched_jobs.py` (the pause flag and `start`'s check);
  - `goal2/tests/test_watched_bench_t102.py`, `goal2/tests/test_watched_jobs.py`;
  - `goal2/tests/test_core_runner_t100.py`, `goal2/tests/test_core_screens_t103.py` (slow marking only);
  - `tools/check_premerge.py` (`SLOW_PATHS` only);
  - `docs/desktop-management.md`, `docs/core.md`.
- **Scope**:
  - **R1.** At a `substitution` decision that carries `requested` pairs, the bench says that Esc keeps them: "Esc: the requested substitutions are still made". The swaps the engine then makes are reported to the bench like any answered swap. The doc line is corrected. The engine's behaviour is not changed.
  - **R2.** The refusal inference is tagged `[derived]` (the words stay `[confirmed: F027 E544]`), and the fallback text is tagged `[designed]`.
  - **R3.** A pause the worker cannot place clears the flag, and the parent learns of it. A later Enter works again. `start(bench=True, frames=False)` raises `ValueError`.
  - **R5.** That test ends its job with `cancel_and_reap`, as the #311 tests do. No assertion changes.
  - **Slow core tests.** The tests in T100's and T103's modules that run the original are marked `requires.need(slow=True)`. Each module keeps one real case in the default run, as `requires`' `keep` allows. `SLOW_PATHS` gains `goal2/core/` and the two test modules, so a change to the core always runs them in full.
- **Done when**:
  1. `python3 -m unittest goal2.tests.test_watched_bench_t102 goal2.tests.test_watched_jobs -v` shows each of the following:
     - Esc at a requested stoppage reports the swaps made, and the bench shows the line.
     - A dropped pause lets the next Enter pause.
     - `start(bench=True, frames=False)` is refused.
     - Every test passes as before.
  2. `GOAL2_SLOW=0 python3 -m unittest goal2.tests.test_core_runner_t100 goal2.tests.test_core_screens_t103` runs in under 3 minutes with at least one real case per module. With `GOAL2_SLOW=1`, every test of both modules runs and passes.
  3. `python3 tools/check_premerge.py --expected-head <sha>` passes. Since `SLOW_PATHS` now covers `tools/check_premerge.py`, that run includes the slow tests.
- **Review**: none (small fixes and test marking; each finding has its test).
- **Hazards**:
  - Don't change what the engine does at Esc: it is the kit's, and probably the original's. Only say it.
  - Marking a test slow must not drop it. The full set still runs with `GOAL2_SLOW=1` and whenever the core changes.
