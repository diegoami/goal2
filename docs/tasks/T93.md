# T93 Localized names for the national pool

- **Kind**: feature (first release, lane 3)
- **Issue**: #295 · **Branch**: `task/T93-pool-names` locally (a cloud session uses its own branch) · **Merge after**: T92
- **Evidence**:
  - [confirmed: F002 R003, F007] The original's national pool is always records 2561..2640 of GOAL.DAT: the managed country's number, one fixed list of mostly English surnames.
  - [designed: owner, 2026-10-21, #295] This is a deliberate departure from the original:
    - common surnames per nation, written for the rebuild (not real players, no GOAL2 data);
    - for the 32 best-ranked countries in GOAL.DAT plus Greece (the demo country);
    - derived from the managed country, never saved;
    - first release.
- **Owns**: `goal2/data/pool_names.json` and `goal2/game/pool_names.py` (both new), `goal2/game/identities.py` (`base`), `goal2/desktop/model.py` (the resolver's cache key), `goal2/tests/test_pool_names.py` (new), `docs/desktop-management.md`, `docs/redesign-253/vision-reconciliation.md` (lane 3).
- **Scope**:
  - Managing a listed nation, pool record 2561+i shows that nation's i-th surname and initial, wherever the record appears (pool, cards, the squad after an exchange, results, ratings).
  - An unlisted nation keeps GOAL.DAT's names. A GOAL.DAT whose country name differs (an ALTER-edited file) also keeps its own.
  - T92 renames apply on top. A rename back to the localized name removes the rename.
  - Nothing is written to the state or the save.
- **Done when**:
  1. `python3 -m unittest goal2.tests.test_pool_names -v` shows each of the following:
     - The data: 33 nations, which are the top 32 by world rank plus Greece. Every number matches its GOAL.DAT name. Each nation has 80 distinct surnames of 1..10 printable CP437 characters and 80 initials A..Z.
     - Managing Greece, the pool view and the cards show the localized names. After an exchange the squad shows the incoming player's localized name.
     - An unlisted country shows the original names.
     - A save made before T93 resumes with the localized names, and the encoded state is the same as without T93.
     - A rename wins. A rename to the localized name removes the entry.
     - A mismatching country name keeps the original names.
  2. The retained desktop scenarios pass (the T91 list) at `QT_SCALE_FACTOR` 1.
  3. `python3 tools/check_premerge.py --expected-head <sha>` passes.
- **Review**: none (presentation data; no save or engine change).
- **Hazards**: Never write the names into player records, the state or GOAL.DAT.
