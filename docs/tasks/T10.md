- **Owns**: `goal2/ui/**` (new package: `grid.py`, `plain_renderer.py`, `__init__.py`); `goal2/tests/test_grid.py`, `goal2/tests/test_plain_renderer.py`
- **Scope**:
  - The character grid (`goal2.ui.grid.Grid`): 80×25 cells. Each cell holds a CP437 character code (int 0..255), a 3-bit foreground colour (0..7), a 3-bit background colour (0..7), and a 1-bit blink flag. The grid is mutable in place; a screen is drawn into it, never into a terminal.
  - The plain-text renderer (`goal2.ui.plain_renderer.render(grid) -> str`): turns the grid into a string. Each row is 80 characters followed by a newline (25 lines total). Colour is omitted in the rendered output — the renderer is for tests and logs, not the user; the grid still holds the colour so a later window renderer can use it.
  - The draw-text operation (`grid.draw_text(row, col, text, fg=7, bg=0) -> None`): writes the text's characters into the grid starting at `(row, col)`, with the given colour. Clips at the right edge (col ≥ 80) and the bottom edge (row ≥ 25): writes nothing off-grid, does not raise.
  - The renderer is the test surface: tests assert the rendered string, not the grid's internal arrays (rule 16: screens are tested by the grid, not pixels).
  - Out of scope: the window renderer (zoom, font, mouse) — a later task; the key/input layer — T11; the state-adapter write — T11; the country list itself — T11.
- **Done when**:
  1. `python -m unittest goal2.tests.test_grid goal2.tests.test_plain_renderer` is green.
  2. `test_grid` asserts the round-trip: `Grid().draw_text(0, 0, "HELLO", fg=14, bg=1)` followed by `render(grid)` yields a string whose first row is `"HELLO" + " " * 75 + "\n"`. The expected string is computed by the test from the input (`"HELLO" + " " * (80 - len("HELLO"))`), not a hardcoded literal — so deleting the `draw_text` call leaves a row of 80 spaces, and the test fails.
  3. `test_plain_renderer` asserts three behaviours: (a) a fresh grid renders as 25 rows of 80 spaces each, joined by newlines; (b) text written past column 80 is clipped (the row ends with the visible prefix, no exception); (c) text written past row 25 is clipped (nothing is appended past line 25, no exception).
  4. The colour values stored on the cells round-trip: after `draw_text(0, 0, "X", fg=7, bg=1)`, `grid.cell(0, 0)` returns `(ord("X"), 7, 1, 0)` (char, fg, bg, blink). A test asserts this without going through the renderer.
- **Hazards**:
  - "Test passes with the grid deleted" (lesson from T05/T09 review rounds): the rendered string must be computed from the input, not a literal — that way an empty grid or a hardcoded render fails the test.
  - "Charset drift": the renderer emits codepoints 0..255, not UTF-8 bytes — the test compares codepoints (Python `str`), so CP437 characters outside ASCII (e.g. `\x9B`) round-trip exactly.
  - "Right/bottom clipping silently": a string longer than 80 cells at `(0, 0)` must not raise `IndexError`; the visible prefix is written, the rest is dropped. The test in Done-when 3(b)/(c) pins this.
  - "Colour drift": the grid stores fg/bg/blink separately; the plain renderer ignores them (it tests the character shape, not the colour). A future window renderer reads them. Tests must not assert the colour through the renderer — Done-when 4 reads `grid.cell` directly, not the rendered string.
