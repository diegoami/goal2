# T225 The v0.1 portable ZIP, for a player with their own GOAL.EXE and GOAL.DAT

- **Kind**: release (packaging; v0.1)
- **Issue**: #705 · **Branch**: the session's `claude/…` branch in a cloud session, locally `task/T225-v0.1-zip` ·
  **Merge after**: T222, T223, T224
- **Why**: [designed: owner, 2026-11-13, #705] v0.1 is published as the portable Windows ZIP; the player supplies
  GOAL.EXE and GOAL.DAT.
- **Evidence**:
  - [confirmed: docs/packaging.md, `.github/workflows/package.yml`] The folder bundles the embeddable CPython 3.13
    (UI) and PyPy 3.11 (workers), built from pinned, hash-checked downloads on the hosted Windows runner; the smoke
    runs from the unpacked ZIP with no Python or Git on PATH; `check-zip` refuses an original-game file. The
    workflow makes "no release, tag or publication" today.
  - [confirmed: docs/packaging.md "The launchers"] `goal2-new.cmd` (the new window) needs the Python route's
    template `e010-r0008-halftime.sav`, a recorded emulator state no player has.
- **Owns**: `tools/build_portable.py`, `tools/portable/`, `.github/workflows/package.yml`, `docs/packaging.md`, a
  player's README inside the ZIP, the release notes `docs/releases/v0.1.0.md`.
- **Scope**: the task protects one claim: **a player with only the ZIP, their own GOAL.EXE and GOAL.DAT, and a
  Windows PC starts a new career and plays a match.**
  1. The ZIP's first start asks for the folder of the player's goal install, imports GOAL.EXE and GOAL.DAT (T222's
     import), and boots the new game from them.
  2. [designed: main session, 2026-11-13; the owner may overrule on #705] The v0.1 ZIP ships `goal2.cmd` only:
     `goal2-new.cmd` needs the recorded template and would fail for every player. It stays in development builds.
  3. A README for players in the ZIP: what goal2 is, which original files are needed and where they come from
     (the player's own copy of goal (version 2); goal2 ships none), how to start, where saves live, the known
     limits of v0.1.
  4. The package workflow's smoke runs the core route from GOAL.EXE: the first-run import, a new career, one
     watched match to full time, under the bundled interpreters, from the ZIP.
  5. The version is 0.1.0 (`pyproject.toml` already says so).
  6. Publication is **not** part of the PR. [designed: owner, 2026-11-13, #705] Once T222–T225 are merged and the
     package workflow passes on `main`, the main session tags `v0.1.0` on that commit and publishes the GitHub
     release at once, with that run's ZIP attached and `docs/releases/v0.1.0.md` as its notes. The milestone
     review and the owner's Windows playtest follow, against the published build.
