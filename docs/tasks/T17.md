- **Hazards**:
  - "Test passes with the write deleted" (L9): the round-trip test asserts the field equals the input — deleting the write makes the test fail (mutation returns the original value).
  - "Captain's offset collides with another byte" — pick an offset not used by the squad, managed_country byte, or `+0x2D` (tactics). The country record is 0xBF (191) bytes; the squad is the first 20 words = 40 bytes; `+0x2D` = 45; `+0x2E` = 46; `+0x2F` = 47 is free. `[designed]` the choice.
  - "The captain field is read by the engine in v1" — it is not (per T14 and `goal2/engine/quick_engine.py`); the vendoring is for state fidelity. A `[designed: captain is UI-only; engine reads `squad[:11]` and `+0x2D` only]` tag at the read site in `from_savestate` is appropriate.
  - "Writing `country_tactics` overwrites the original byte (loses data)" — only if the original byte is non-zero; for the round-trip test the input is `0x8B`. For a real round-trip (load → modify tactics → save → load), the new byte is exactly what was set.
  - "Round-trip via `to_savestate(state, original)` may not match byte-for-byte" — the existing `to_savestate` already preserves unknown bytes via zip-rewrite (`_rewrite_zip`). Only the country record's relevant offsets are modified.
