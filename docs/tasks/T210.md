# T210 The foundation, part 2: the frame as a rule with its label, and a grid check

- **Kind**: UI foundation (second of two), on the integration branch `ui/foundation-32`
- **Issue**: #667 · **Branch**: `task/T210-frame-grid` from `ui/foundation-32` · **Merge after**: T209
- **Evidence**:
  - [designed: owner, 2026-11-08] `fidelity-review.md` §3: panels touch and nest, separation is one empty cell, no
    interior padding; **a frame is a rule with its lowercase label sitting on it, the rule continuing as dashes to the
    panel's edge** (`-rankings-`, `-characteristics-`), brown or red; the card and its uppercase cyan heading go. The
    proposal draws it (`proposal/README.md`; primitives in `proposal/grid.py`).
  - [designed: main, 2026-11-09, owner's route for T209] About 25 screens overflow at T209's 32 px and are reflowed
    in groups (T211–T214). Laying each screen out twice, once to fit and once for frames and grid, would be waste:
    this task builds the **shared parts** once, and each group task uses them for its screens.
  - Today the screens use bordered cards: `#box`, `#boxHeading` in `goal2/ui/theme.py`'s `stylesheet`.
- **Owns**: a frame widget (a rule with its label and dashes) in `goal2/ui/`; `goal2/tests/grid_pending.py` (a shrinking
  list of screens still off the grid or still with a card, like `reflow_pending.py`, with its `assert_on_grid`
  helper); `goal2/tests/test_ui_grid_t210.py`; its own docs (`docs/design/ui-2026-11/README.md` §3, the frame).
  **No screen is reflowed here.**
- **Scope**: the frame widget, drawn at the cell with the palette's brown/red; a helper that walks a window's widgets
  and reports every rectangle whose x, y, width or height is not a multiple of the cell, and every card; the list of all
  screens as pending. The claim: **the frame and the check exist, and a screen not on the list is on the grid.**
- **Done when**:
  1. `python3 -m unittest goal2.tests.test_ui_grid_t210` passes, and fails on the branch before the change: the frame
     draws `-name---…` to its panel's edge in the palette's colour at the cell; the check reports an off-grid widget and
     a card in a synthetic window; a listed screen must still be off the grid (the list only shrinks); a screen not
     listed must be on the grid with no card.
  2. A test: `test_grid_pending_is_empty` fails while the list is non-empty and skips unless the target branch is main
     (the same mechanism as T209's `test_pending_reflow_is_empty`).
  3. `python3 tools/check_premerge.py --expected-head <sha>` passes.
- **Hazards**: a frame that is a Qt border (not on the cell); a check that counts Qt's internal parts (`qt_`-named
  widgets: `fixed_page._own` already filters them); drawing the label as text over a border instead of making the rule
  the frame.
