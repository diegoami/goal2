- **Evidence**:
  - [confirmed: T170's Done-when 1 and 2] A career starting **1992/stage 2** plays all
    fixtures/rounds through the terminal boundary without `UnsupportedCampaignTransition`; every

    difference is reported by field, record and byte. **Import it unchanged.**
  - [confirmed: `docs/assumptions.md` ROUND-AGEING-1] The reached 2→3 transition executes

  - [confirmed: `docs/core.md`, F033/E039/NG-10] `Core.boot(state, date)` answers the DOS date call

- **Scope**: The task protects one claim: **a 1992/stage 2 career plays its whole season on the
  sealed route exactly as the original plays it, round by round, to the terminal boundary.**
  1. **Which start.** [designed: owner, 2026-11-09, after this task stopped on its first wording]
     A **stage-2 career at cursor 1**, built in the test by the original's own keys:
     `Core.boot` on `.cache/e039-r0005-date-call.sav`, then `Driver.new_game(...)` to the first
     manager menu. No guest-memory edits, and **no new stored artifact** — the start is rebuilt
     each run. "1992/stage 2" names the cycle position, not the calendar year (T170's Done-when 1,
     as amended): by NG-9 a start year divisible by four begins at stage 2, and the comparison
     drives both sides from the same start, so the year cannot affect it. Report the start's
     stage, cursor, count and start year in the test, and the wall clock the boot costs.
  2. **Every round.** Each completed round is compared, not a sample. The round that crosses
     **2→3** is identified in the test by name, and its ageing is asserted (players aged, the
     stage before and after).
  3. **The terminal step** is compared at `stage=4` with the original paused at its oracle site,
     `cursor=count, rounds=1`. Do not advance rounds or stage, and do not call rollover.
  4. **Repeats unchanged.** Running the same season twice from the same start gives the same final
     results and news. This is T170's own words and the same property T170c2 proved for
     publication.
  5. **A difference is a finding.** If a round differs, stop and report it with the field, the
     record and the round, and file it as #693 was filed. Never edit anything under
     `goal2/engine/` (CLAUDE.md rule 13), and never relax the comparison to make a season pass.
  6. **Slow by nature.** Gate the season with `requires.need(slow=True)`; a default run skips it
     with its reason. Full runs are CI's (process.md §3).
  7. **No product change.** `season.py`, `season_publication.py`, the engine, the worker, the wire
     and the UI are untouched.
