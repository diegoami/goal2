- **Scope**: The new window takes a player from the first start to a new or loaded career, as in the design's
  journey: S01 → S02 → (N) S03 → S04 → S05 → home, or S02 → (Enter or Y) home. The home is T162's placeholder,
  showing the career's summary; T164 replaces it with the desk. The task protects one claim: **a career started
  or loaded in the new window is the same career the Python route's model makes**: the same country, manager,
  start year, stage, fixtures and squad as `DesktopModel.new_campaign` or `resume` with the same inputs.
  1. **S01 for the new window.** Its required files are GOAL.DAT and the Python route's template
     (`e010-r0008-halftime.sav`, pinned by hash). GOAL.HLP stays optional. The Core's boot state is not asked for
     by the new window.
  2. **S02 Start.**
     - *Continue* (Enter) opens the newest save.
     - The list shows each save's free name, country, year and stage, next match and time saved, read through
       the model's validating loader.
     - **Y** loads the highlighted save; **N** goes to new game; Esc quits.
     - A save that cannot be read says why on this screen, with **Y** try again and **N** back. With no save,
       only *New game*.
     - Saves live in the data root's `saves` folder (`data_setup.Paths.saves`). The free name is stored with the
       save, not only in the file name: a file name is derived safely from it, and the list shows the stored
       name. T168 adds saving under a name; this task defines the format and reads it.
  3. **S03 New game.**
     - The six numbers, 1 chosen. 2–6 are shown and marked *coming later* (#551); choosing one does nothing but
       say so.
     - The optional year field: empty means the PC clock's year. Either way goal2 applies NG-9's rule (+1, rounded
       up to even), and the screen shows the resulting start year and its first competition.
     - Enter accepts, Tab moves to the year field, Esc goes back to S02. A busy line shows while the game is
       prepared.
  4. **S04 Country and name.**
     - The country card as the mockup shows it: what today's browse page shows, in the new look, with fields not
       yet decoded saying so, as today.
     - The list in groups of 16, ↑↓ and ←→, **Ins** world/continental ranking, **Space** the country's twenty
       (read-only player card).
     - **Enter** chooses the country, then the name line (14 characters at most) on the same screen; **Enter**
       accepts it, and **Esc** aborts the name, then goes back.
  5. **S05 Bulletin.** The screen, as pages *n of m* of the mockup's three panels, with Enter for the next page and
     then on. The Python route has no bulletins yet: today's come from the original's memory on the Core route
     (`goal2/core/views.py`), and the news text is Track B's port (U2, #509). So S05 is built and tested with the
     test's own stand-in pages, and the new-game flow goes S04 → home until a career has bulletins. The flow
     shows S05 whenever the career supplies pages. [designed: owner, 2026-11-03, #509]
  6. **S22's text box** fills most of the screen (owner decision 13).
  6a. **Gaps found by the main session's audit, 2026-11-03:**
     - **S04's players view** (Space) uses T165's card (`goal2/ui/squad_card.py`), read-only: bars without
       numbers (the owner's T99 rule), with performance and cards, as S08 shows them.
     - **S04's card** shows *average caps and age*, from the twenty's cards (design S04 *Shows*).
     - **S22's no-help message** must not name `python -m goal2.desktop.data_setup`: that imports the old manifest,
       which needs the Core's boot state. Until T164's *re-import data*, it says to start goal2 with the folder
       holding GOAL.HLP, through the new window's own import, and that command is tested.
     - **S02's Esc** (quit) and **S03's busy line** get tests.
  7. Mouse equals key on every screen, as T162's base class gives.

  - **Fixing the old window.** `goal2/desktop/` stays as it is (apart from reading its model and data paths);
    T169 retires it.

    those files are absent; nothing is committed.
