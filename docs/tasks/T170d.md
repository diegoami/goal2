- **Owns**:
  - A comparison helper, `goal2/tests/season_oracle.py` (test support, not product code), or an
    equivalent module the two season leaves import.
  - `goal2/tests/test_season_oracle_t170d.py`.
- **Scope**: The task protects one claim: **for the same career, the same keys and the same match
  answers, one sealed round and the terminal step leave the game in the state original Core leaves
  it in, field by field.**
  1. **The compared fields** are T170's own: countries, players, fixtures, the game block,
     `[DS:A91F]`, 7B62 and 8336. A difference names the field and the round, never "states differ".
  2. **Same keys, same answers.** The Core side is driven through `play_round` with the identical
     key policy and match answers the sealed route is given. Core's timed polls normally get no key
     unless queued (T170's hazard): use the route's identical policy, do not invent one.
  3. **The terminal step** is compared at its declared oracle site — the explicit upstream rollover
     boundary before `stage_end` at `cursor=count, rounds=1, stage=4/8` — with the original paused
     at that same site. Do not advance rounds or stage, and do not call rollover.
  4. **One round, not a season.** This leaf proves the oracle on a single completed round and one
     terminal step. It does not play 1992/stage 2 or 1994/stage 5 to their boundaries; those are
     T170e and T170f, which import this helper unchanged.
  5. **Slow by nature.** The Unicorn comparison is a slow case: gate it with
     `requires.need(slow=True)` and leave full runs to CI, as process.md §3 has it.
  6. **No product change.** `season.py`, `season_publication.py`, the engine, the worker, the wire
     and the UI are untouched. If the comparison cannot be made without a product change, **stop
     and report it** — that is a finding about the route, not licence to edit it.

## Done when

1. `GOAL2_SLOW=1 python3 -m unittest goal2.tests.test_season_oracle_t170d` passes, and fails before
   the helper exists. It shows:
   - one completed sealed round equal to Core's `play_round` on all seven fields above;
   - the terminal step equal at its declared oracle site, with the original paused there;
   - a deliberately corrupted expectation is reported with the field's name and the round, so a
     real difference could not pass unnoticed.

   the slow case with its reason, so a default run stays fast.

   goal2.tests.test_owned_match_driver_t170c1 goal2.tests.test_season_publication_t170c2` passes
   unchanged; the PR names any assertion that moved, and why.

- **Hazards**:
  - **The oracle must be able to fail.** A comparison that cannot report a difference proves
    nothing: Done-when 1's third bullet exists for that reason. Do not satisfy it by asserting on
    a hash alone when the task asks for the field's name.
  - **Key policy drift.** If the two sides are driven by different key policies the comparison is
    meaningless even when it passes.
  - **Scope creep into T129p.** Pre-match policy, the pool view and automatic XI belong to the
    upstream contracts (#703/#704), which another session owns.
  - This leaf does not complete #566: T170e, T170f and the worker/UI lifecycle remain, and
    required T183 (#594) follows them.
