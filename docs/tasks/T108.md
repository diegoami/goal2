- **Scope**:
  - **The screens.** Every screen of a round from E006-r0001's manager menu, and from a T106 new game, is mapped by its frames or a cited field, with its view. That runs through the fixtures, the watch prompt, captain, menus, play, half time and bench, the summary, the results and the bulletins, back to the menu. A screen no tour reaches stays `UnknownScreen`, listed in `docs/core.md`.
  - **The driver.** `play_round(watch=False)` plays the original's keys from the manager menu to the next manager menu. The desktop is asked only where the original asks the manager:
    - **the captain:** the player's pick, or the original's own choice (C);
    - **the half-time menu:** play on, or the bench, where `substitute(off, on)` is the original's own SELECT TEAM keys and the counter is the original's;
    - **a stoppage's substitution notice;**
    - **the save prompt:** answered no unless the player asks.

    The own match is played as the original's quick result: R at the first `match-live` poll. The original still stops at half time, which is where the bench is. Other matches of the round run as the original runs them.
  - **The desktop.** On the core route, **Play next game** is enabled. It runs the round as a background job (T107's `CoreJobs`) and shows goal2 pages, each passing `fixed_page.problems()` with the 90% margin and measured in the bundled font:
    - the captain choice (the roster strip);
    - the half-time board with the score and the bench (T102's bench page, filled from the core: eleven, bench and substitutions left);
    - the result and summary;
    - the round's results;
    - each bulletin.

    The pitch view stays with the Python route until G14b, and the core route says so.
  - **Keys the original's code reads** (amended 2026-10-23, after the first attempt). A kinds.tsv kind also accepts a key when both of these hold:
    - its screen's routine reads and acts on the key, cited in the named listing (for SELECT TEAM in a match, `u214b_menu_move_word_wrap(0x14, 0xC1B)` in E44F's in-match branch, `named/seg_0791_11.c`);
    - a recorded run read it on that screen (the catalogue's `burst` rows, for `squad-substitution-take-off`/`-put-on` ↑↓ from E015-r0007 state 76 on).

    Each such key is listed in `docs/core.md` next to T107's printed keys, with both citations. T103's catalogue-keys test checks the union and that each added key carries both.
  - **A text rule narrower than its screen.** When a site is clearly a kinds.tsv kind (its routine and frames say so) but the kind's text rule misses a case, the kind stays as it is. Example: `round-results` requires "friendly", which a qualifiers-only round lacks. The gap is recorded in `docs/core.md` with the text, the oracle's exception covers only that documented case, and the PR body proposes the rule fix for goal2-archaeology.
  - **The pre-match SELECT TEAM** (0791:E44F from 0791:E949, before kick-off) is mapped too. When the original refuses the eleven before a match (EA09: "<country> has an ineligible player in the first team"), the desktop shows that message and the player fixes the eleven on that screen, with the original's keys through the driver (T107's actions). The match then goes on.
