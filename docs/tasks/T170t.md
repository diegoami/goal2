# T170t Lossless news snapshots over the season pipe

- **Kind**: worker activation bug fix; **Issue**: #751.
- **Branch**: `task/T170t-season-news-wire`; **Merge after**: T170s/#750.
- **Evidence**: [confirmed: archaeology `fb6d3093`, F039, route/news]
  A completed round returns immutable `NewsPageMemory` with 4000 raw cell bytes
  and provenance. [confirmed: T170s at `d56b5335`] Actual complete/resume has
  one fixture and one news snapshot. `asdict(SeasonObservation)` preserves
  those bytes, but the existing season Server.send uses the save JSON encoder,
  which rejects bytes. A genuine synthetic NewsPageMemory through actual
  Server._season/send/read_packet yields `season_error`, `lost=true`,
  `unsupported session value: bytes` (#751 reproduction).
- **Owns**: season-specific packet encoding/decoding in engine server/process
  (a small codec module if needed), focused protocol/worker tests and docs.
  No vendored engine, window, generic save-schema or route-result changes.
- **Scope**: carry every original news cell byte and provenance field losslessly
  across the pipe, retaining ordered duplicate pages, tuple values, and existing
  observation/state integrity checks. Keep preview separate. Decode into the
  same detached data shape exposed by the worker; never replace original cells
  with only decoded text, trim pages or cache state for implicit replay.
- **Done when**:
  1. Focused actual Server/EngineProcess tests fail on the pre-fix byte
     refusal and then round-trip genuine synthetic news snapshots, including
     distinct provenance, identical/duplicate pages, all cell bytes and tuple
     fields. Malformed cell encoding/metadata and corrupt state hashes refuse;
     no generic save-format change is accepted.
  2. A focused real PyPy fixture completes Play/resume through EngineProcess;
     boundary state, ordered fixture/news deltas and exact raw page/provenance
     data equal the direct worker control. Repeated observe has empty deltas;
     preview and repairable request guards still work. Print only metadata or
     digests, never actual original cells/state bytes.
  3. Focused season/protocol/preview regressions, clean-head
     `python3 tools/check_premerge.py --expected-head <sha>` and required
     Linux/Windows checks pass. Full slow suites stay at the milestone.
- **Review**: owner's m3 milestone; no per-PR review.
- **Proof**: [confirmed: `125c158b`] Nineteen focused regressions include full
