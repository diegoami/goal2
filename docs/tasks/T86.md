- **Kind**: slice (first of two for #260; T87 owns the Game save menu and the replacement/quit decisions)
- **Issue**: #260 · **Branch**: `task/T86-launch-and-new-career` locally (a cloud session uses its own branch) · **Merge after**: T50
- **Evidence**: [confirmed: E015-r0001 state 2, M244-G1A-01, E015-r0008 state 10, E031 C11–C15b; docs/original-game/startup-save-replay.md] the original's title asks load or new, the load branch offers *try again* after a missing file, and new games browse countries with their rankings. - **Owns**: `goal2/desktop/launch.py` (new), `goal2/desktop/__main__.py`, minimal Qt-free summary hooks in `goal2/desktop/model.py`, `goal2/tests/test_desktop_launch.py` (new), `tools/desktop-ui/launch.py` (new), `docs/desktop-management.md`.
- **Scope**: Starting the desktop without `--resume`/`--country` opens a Launch window in the accepted original style (black, large coloured text). The **Saved career** panel reads the save at `--save` and names its country, the manager (the current one-manager default, with the naming limitation stated: #265), campaign year and stage, next and following fixture, the checkpoint (before the next fixture) and the confirmed team (20 players, captain). **Resume** validates the complete candidate before opening management. **Open another save** takes a path. A missing, corrupt or incompatible save shows the reason with **Retry** and **Load another**, and nothing else changes. **New career** browses all 128 countries with world rank and continent. Browsing previews the country's identity and roster (names, positions, ability; the profile categories the original shows and this build lacks are named as unavailable, O12/G05). The start year is 1990 or 1992. A **Review** step lists country, manager, start year and first stage, and first fixture, before **Start career** creates it. Browsing and review never write a save or replace anything. Keyboard operation matches the hint line: arrows choose, Enter accepts, Esc goes back. Out of scope: Save as, overwrite and quit prompts (T87); editable manager names (#265); several managers (#264); full country profiles (G05).
- **Done when**:
  1. `python3 -m unittest goal2.tests.test_desktop_launch -v`: summary fields of a real save; Resume equals `DesktopModel.resume` of the same file; a missing, a corrupt and an incompatible save each give a reason with Retry/Load another and leave the save bytes and any open game unchanged; New career browsing and Review write no file and draw no RNG from any existing state; Start career equals `new_campaign(country, year)`; arrows/Enter/Esc drive the same actions as the mouse.
  2. `python3 tools/desktop-ui/launch.py --template .cache/e010-r0008-halftime.sav --data .cache/GOAL.DAT` passes offscreen and under `xvfb-run` with `QT_SCALE_FACTOR` 1 and 2, at 1440×900 and 900×640: every control reachable by keyboard and inside the window; Resume, failure/Retry, Load another, and New career → Review → Start through real input.
  3. `python3 tools/check_premerge.py --expected-head <sha>` passes.
