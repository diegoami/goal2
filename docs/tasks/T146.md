# T146 Provisioned Linux PR gate

- **Kind**: infrastructure
- **Issue**: #467 · **Branch**: `task/T146-linux-gate` · **Merge after**: T145
- **Evidence**: [confirmed: `.github/workflows/ci.yml` at dff5bea] dispatch-only, 20 minutes, no
  extras, no original files, no goal2-archaeology clone: not the local Linux gate.
  [designed: owner, 2026-10-29] The Linux gate moves to CI like the Windows one (#278).
- **Owns**: `.github/workflows/ci.yml`, `goal2/tests/test_ci_workflows_t146.py`, `docs/process.md` §3
  (the sentence on CI), `measurements/T146/**`.
- **Scope**: `ci.yml` runs on every PR, on `main` and on dispatch (with a `slow` input), on a pinned
  Ubuntu image: the Qt/SDL system libraries, the `desktop,watched,match-view` extras, the original
  files from the owner's Drive through the existing `GOAL2_RCLONE_TOKEN` secret (verified with
  `tools/check_goaldat.py`), the full goal2-archaeology clone, then `check_premerge.py` with its own
  slow choice. On a same-repository event a missing secret fails the job; only a fork PR skips the
  original-file tests, and says so. The timeout is set from a measured slow run with margin, and
  stays under GitHub's six-hour job limit. It uploads only logs, with the Windows workflow's
  original-extension refusal. Nothing of the original game is cached or uploaded.
- **Done when**:
  1. `python3 -m unittest goal2.tests.test_ci_workflows_t146 -v` fails before and passes after:
     triggers, pinned image, timeout from the measurement, assets/archaeology steps before the gate,
     fail-on-missing-secret for same-repository events, upload refusal filter, no `.cache` upload or cache.
  2. A green Linux run at the PR head whose log shows `GOAL.DAT verified`, the archaeology clone,
     and a skipped-test count no higher than the local gate's at the same head
     (`measurements/T146/run-<id>-v1.json`).
  3. `python3 tools/check_premerge.py --expected-head <sha>` passes; Windows green.
- **Review**: none, unless the secret handling changes.
- **Hazards**: a missing secret silently turning into skipped tests; uploading `.cache`; `sudo` making
  `.cache` root-owned; a timeout guessed instead of measured.
