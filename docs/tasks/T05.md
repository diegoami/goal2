# T05 The P1 fidelity test: an end-to-end check that goal2's new game produces the same player array and skills as E006

- **Kind**: measuring
- **Issue**: #<new>
  **Branch**: `task/T05-p1-fidelity` · **Merge after**: T04
- **Implementer**: the main session
- **Reviewer**: `luna` (the test is a measurement, not an engine seam; the lighter reviewer fits)
- **Evidence**: E006-r0001 (the main-screen savestate) and E007-r0009..r0012 (the 80 player screens). F007 (the new-game player creation) and F008 (the 12 skills). The test asserts what T02, T03 and T04 produced against the archaeology's published records.
- **Owns**: `goal2/tests/test_p1_fidelity.py` (the integration test), `tools/measure_p1.py` (the measurement script that prints the §9 numbers).
- **Scope**:
  1. The integration test: loads GOAL.DAT (T02), runs `make_all_players` (T03) and `skills` (T04), and compares against the E006-r0001 player array and the E007-r0009..r0012 skill bars. The test skips with the reason when any fixture is absent.
  2. The structural fidelity check: all 3061 player records have the right country byte, +0x03 potential, +0x06/+0x07 position, +0x12/+0x13 fitness word (T03's structural fields). The 12 skills per player match E007 (T04's 960 bars).
  3. The LCG gap measurement: count the byte mismatches in the LCG-driven fields (+0x01 age, +0x02 peak, +0x05, +0x0C) and print the number. The current model has ~11,000 of 61,220 byte mismatches (T03's known gap, tracked in #11).
  4. The measurement script: `python3 tools/measure_p1.py` prints the player array length, the structural match count, the skill match count, the LCG-driven mismatch count, and the names of the 4 countries and 20 players per country (one per slot) for a sanity check.
- **Done when**:
  1. `python3 -m unittest goal2.tests.test_p1_fidelity` is green (skipped with the reason when any fixture is absent).
  2. The structural fidelity check: all 2560 squad players have the right country byte, +0x03 potential, +0x06/+0x07 position, +0x12/+0x13 fitness word against E006-r0001; all 80 managed-country players (2561..2640) have the right country byte.
  3. The skill fidelity check: all 960 skill bars match E007-r0009..r0012.
  4. `python3 tools/measure_p1.py` prints the §9 numbers: 3061 records, 2560 structural matches, 960 skill matches, and the LCG-driven mismatch count.
- **Hazards**:
  - the test depends on three fixtures (GOAL.DAT, E006-r0001, E007 runs); each fetch can fail and the test must skip with the reason;
  - the LCG-driven fields are a known gap (issue #11); the test must not fail on these, only report the mismatch count;
  - the structural check must catch a no-op model (all-zero records) and a degenerate LCG (always-1 returns); the skill check must catch a no-op skills function (all-zero bars);
  - the measurement script must not commit a savestate (rule 19); it reads from `.cache/` and the archaeology repo only.
