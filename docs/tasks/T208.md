- **Scope**: The task protects one claim: **the check passes every original screen and fails a
  screen with a region of no ink.**
  1. **The measure.** For each PNG, a 4×4 tiling; for each tile the mean of its pixels' luminance
     as a percentage. A screen fails when any tile is under a floor, default **1.5 %** (the
     original's own minimum is 1.83 %). The output prints the 4×4 table for a failing screen, so
     the message says which region is empty.
  2. **No new dependency.** The repository has no image library, and the runners may have no
     ImageMagick. Decode the PNG in the checker: `zlib` for the data and the five PNG filter
     types, which is enough for the committed screens (8-bit RGB/RGBA, no interlace). A file it
     cannot decode is reported by name, never silently passed.
  3. **The command** takes paths or folders: `python3 docs/design/ui-2026-11/check_density.py
     <path>...`, exits 0 when every screen passes, non-zero with the table otherwise, and
     `--floor` overrides the default for a deliberate exception.
  4. **It is not wired into any gate yet.** #667 reflows every screen; wiring the floor into the
     UI tasks' Done-when lines belongs to that work, not this one.
