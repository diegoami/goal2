- **Scope**: The player saves a career under a name of their choice, quits as the original asks, and never loses
  progress silently. The task protects one claim: **a career saved in the new window loads back equal, and
  nothing the player did since the last save is lost without a question.**
  1. **F7, save** (from the desk, and from any management screen that shows F7).
     - S21's box proposes the last name used (the loaded save's, or none for a new career). Type or accept it,
       **Enter** saves through `saves.write`, **Esc** cancels.
     - Saving under another save's name asks before replacing it.
     - A failed save says why, and nothing is replaced.
  2. **F10, quit.** *Are you sure you want to quit?* **Y**/**N**. Then, if anything is unsaved, *Do you want to save
     this game?* **Y** (S21's name box, then quit) or **N** (quit).
  3. **The window's close button** asks the same as F10's second question when anything is unsaved: save,
     don't save, or cancel (stay). During a match, closing cancels the match first, as T166 does.
  4. **Unsaved** means progress since the career was created, loaded or saved, as the model's `unsaved` reports.
  5. **S02** lists the new save at once with its name, newest first.
- **Done when**:

       with `view()` equal and the name shown.
     - **Replace:** saving under an existing name asks first. N keeps the old file, Y replaces it.
     - **Quit:** F10 then N stays. F10, Y with nothing unsaved quits with no second question. F10, Y with unsaved
