- **Scope**: The management window gets a **Game** menu: **Save** (Ctrl+S), **Save as…** and **Quit** (Ctrl+Q). The Save page gets the same Save as. The model records the state it last saved, resumed or created. Confirmed changes since then are **unsaved progress**. A management draft that differs from the confirmed team is an **unconfirmed draft**, compared as a set, so the engine's squad reorder (#280) is not mistaken for an edit. New campaign, New standalone friendly, Resume and Quit (menu, shortcut or the window's close button) ask first when either exists. The question names what would be lost and offers **Save and continue**, **Continue without saving** and **Cancel**. Save never confirms a draft; it saves the confirmed state and says the draft is excluded. A failed save shows its reason and the decision stays pending: nothing is replaced and the window does not close. Save as to a different existing file asks before overwriting. Saving while a match runs stays refused; quitting then says the match will be cancelled. Mouse and keyboard reach every choice. Out of scope: save-name lists and original `.GL` files.
