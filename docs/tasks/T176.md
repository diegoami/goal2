- **Scope**: A scheduled qualifier of the managed country can be played watched, with the pitch samples, the
  bench and the decisions, exactly as a watched friendly. It is published through the competitive publication, as
  competitive Play is today. The task protects one claim: **a watched qualifier is the same match the original
  plays with the same answers.** Its events, decisions, outcome and published campaign state must equal
  `_drive_match` on `prepare_competitive` for the same fixture, seed and answers.
  1. **The controller.** `WatchedController` (or a competitive counterpart sharing its API) accepts the next
     fixture when it is a qualifier, and starts it with `kind: competitive` and frames and bench on the engine
     process. Friendlies are unchanged.
  2. **Substitutions.** The bench offers the owner's BM-7 budget (`docs/assumptions.md`; #73): five in a competition
     match, the same as competitive Play, where the original allows two. A test pins it: the bench refuses one
     substitution more than the budget.
  3. **Publication.** A watched qualifier's completion is published once, by the competitive publication, with
     the same campaign state as competitive Play's for the same match and answers.
  4. **The old window keeps working.** Today's window still offers both Play (quick) and Watch for a qualifier,
     since the old window is not redesigned. The new window's match screens (T166, T167) use the watched path.
