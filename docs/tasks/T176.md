# T176 A manual of the build as it ships, with its own screenshots

- **Kind**: documentation
- **Issue**: #664 · **Branch**: `task/T176-current-game-manual` · **Merge after**: —
- **Evidence**:
  - [designed: owner, 2026-11-08] The original has a manual with its screens
    (`docs/original-game/`, T156's playthrough); the rebuild has none. Comparing the two means
    running the build and remembering what it looked like, which is why the look is reviewed in
    circles. This task writes the rebuild's half so the two can be read side by side.
  - The build's routes are `goal2/desktop/__main__.py`: the player's own route is `--core-boot`
    (T106, T153), with `--template` and `--core` beside it for scripts.
  - The capture pattern is the existing offscreen Qt acceptance tools (`tools/desktop-ui/launch.py`,
    `animated-pitch.py`); the original's own method is `docs/original-game/capture-method.md`.
  - The design the build is measured against is `docs/design/ui-2026-11/README.md`.
- **Owns**:
  - `tools/desktop-ui/manual-screens.py`: the capture tool.
  - `docs/current-game/`: `README.md`, `capture-method.md`, `flow.md`, `screen-inventory.md`,
    `match.md`, `images/`, `image-provenance.tsv`, `check_manual.py`.
  - A pointer from `docs/original-game/README.md` and `docs/desktop-management.md`.
- **Scope**: Record what goal2 shows today, screen by screen, from the real windows. The task
  protects one claim: **every screen in the manual is a grab of the shipped window, and the
  manual accounts for every grab.**
  1. **The tool** opens the real windows offscreen at the fixed page's 1440×900, walks the
     player's route (`--core-boot`), the `--template` route and a whole round (`--round`), and
     grabs each screen with a provenance row: the route, how it was reached and the PNG's
     SHA-256. With `--pitch` the match is watched, and the shipped pitch window saves its own
     post-flip surface. A screen it cannot reach is reported, never invented.
  2. **The manual** has the original manual's shape: an index, the capture method, the flow, a
     screen inventory with one row per screen, and the match. Each screen says what it shows,
     which keys it takes and which original screen it stands for, citing
     `docs/original-game/screen-inventory.md`. Where the build has no equivalent, or shows
     something the original does not, the row says so.
  3. **No original byte** enters the repository: the images are the rebuild's own pixels
     (CLAUDE.md rule 14). The savestates the capture reads stay in `.cache/`.
  4. **The checker** `docs/current-game/check_manual.py` exits 0 only when every row's image
     exists with its recorded hash, every PNG has a row, and every screen is written up.
