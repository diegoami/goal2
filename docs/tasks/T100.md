  - [derived: `docs/estimates/99-original-engine-plugged-in.md`, Stage 3 G8 and risk R1] The main loop runs from the main-screen state. Each key read is a yield point. The save is the image with its seeds, so a game replays.

  - [confirmed: goal2-archaeology F030, E031 `docs/play-guide.md`, `docs/screens.md`] The screens, their keys, and the timed prompts (6 s and 10 s waits).

  Nothing under `goal2/engine/` is edited. The kit is imported, and its `Machine` and `Image` are reused as they are.
- **Scope**:
  - `Core.start(image)` runs the original's own main loop from the main-screen image. It stops at the first key the original reads and returns a `KeyWait` with:
    - `site`: the `SSSS:OOOO` return address of the 214B:08DD call;
    - `text`: the 80×25 text page, CP437-decoded;
    - `state`: a read-only view through the kit's `Image`, holding at least the managed countries and the year.
  - `core.press(key)` answers the wait and runs to the next one.
  - A "key pressed?" poll (214B:0723) answers "no key" unless one is queued, so a timed prompt advances on the original's own clock.
  - A run that executes more than a declared instruction budget without a key read stops with an error naming the PC and the text page. It never guesses a key.
  - `core.save()` returns bytes holding the compressed image, the CPU, the seeds and the key log. `Core.load(bytes)` resumes exactly.
  - `unicorn` stays optional: importing `goal2.core` works without it, and `start` says what is missing.
  - **R1, how to enter the loop.** If the image does not carry the CPU at the main screen, enter at the original's own main-menu routine, found in goal2-archaeology's named listings and cited. If a hidden precondition blocks the entry, stop and report to the main session with the evidence. Never patch bytes to get past it.

- **Hazards**:
  - Never answer a key read the original did not make. Never write a byte into the image to skip a screen.
  - A savestate's memory is the master (F029). The core's save must replay draw for draw.
  - No byte of the original enters the repository: tests read `.cache/` and skip without it.
