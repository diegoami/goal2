# T98 A Windows GitHub Actions workflow on every PR

- **Kind**: tooling
- **Issue**: #278 · **Branch**: `task/T98-windows-ci` locally (a cloud session uses its own branch)
- **Evidence**:
  - [designed: owner, 2026-10-20, #278] Native Windows checks run on hosted runners, which are free for a public repository.
  - [designed: owner, 2026-10-21] Windows is tested both by this workflow and at the 0.1.0 milestone.
- **Owns**: `.github/workflows/windows.yml` (new), `docs/process.md` §3, `docs/cloud.md`.
- **Scope**:
  - Runs on `windows-latest` with Python 3.12 and `.[desktop,watched,match-view]`, at the PR's head with full history.
  - With the `GOAL2_RCLONE_TOKEN` secret, it pulls the original-game files with rclone (pinned and verified). Without it (fork PRs), those tests skip.
  - Takes a full goal2-archaeology clone.
  - Runs `check_premerge.py` (`--slow` on dispatch). With the original files, it also runs the worker, management, launch, friendlies, page and watched two-window scenarios with the native platforms.
  - Uploads screenshots and logs only. It fails if a file with an original-game extension reaches the upload.
- **Done when** (#278):
  1. The workflow runs green on this PR, and its log shows the game tests ran on Windows (the module count and skips).
  2. A deliberately Windows-only fault fails on the runner and passes once removed (a worker entry point that only works under `fork`), red then green on this PR.
  3. The uploaded artifact holds screenshots and logs only: no original-game extension, no `.cache/` content.
  4. `docs/process.md` §3 and `docs/cloud.md` say what the workflow covers and what stays with the owner.
- **Review**: none (tooling).
- **Hazards**: never upload `.cache/` or an original file; never echo the token.
