- **Scope**: [designed] Provide an explicit experimental Core match job over the records request, without connecting it to default desktop execution. Use the delivered public event, decision/answer, refusal, pause and pitch/board snapshot API; do not inspect opts, _squad or guest memory. Bind each message to the job/request identity, monotonic event/frame sequence and acknowledgement watermark. Keep computation off the UI thread, bound transport growth and preserve backpressure. Reject stale/duplicate answers and unknown waits; incomplete/error/cancelled jobs cannot offer completion. Reap children and close all reader/writer handles before removing temporary files, including startup failure and cancellation. Use deterministic subprocess synchronization for lifecycle tests rather than timing-only sleeps. This is the Core's new worker seam, not automatic adoption by the older watched worker.
