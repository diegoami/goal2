- **Scope**:
  - **A second entry kind: resume at a DOS call.**
    - `Core.boot(state, date=(year, month, day))` loads `e039-r0005-date-call.sav` with its registers and checks that the CPU is at the date call's `int` (cited).
    - It answers AH=2Ah with the date, as DOS does (CX year, DH month, DL day, AL weekday), then continues at 235C:0073 and runs to the title's read.
    - Speaker port I/O is ignored, and any other interrupt stops with `InterruptError`.
    - The date is stored in the core save.
  - **The runner serves the new-game interrupts.**
    - `Intr` and `MsDos` are hooked at their entry. The register record and the vector are read from the stack, served, written back, and the call returns with `retf 6`.
    - `GOAL.DAT` comes from the path the player gives (`--data`), never from the repository.
    - Any other request through `Intr`, or any other interrupt, still stops with `InterruptError`.
  - **The DOS time is an input.** AH=2Ch answers with a time the caller declares: `Core.start(..., dos_time=(h, m, s, cs))`. The default is a fixed time, documented. The time is stored in the core save, so a game replays exactly.
  - **The screen table** gains `title-load-prompt`, `title-player-count`, `country-select`, `country-select-name-entry` (polled) and the two bulletins' sites, each cited.
  - **The driver and the views:**
    - `new_game(country, manager_name, managers=1)` plays the original's own keys from the title to the first manager menu: N at the load prompt, the player count, the country chosen by its arrows, the name letters queued at the polled name entry, and Enter through the bulletins.
    - The country browser's view reads the browsed country and its team from memory, which the desktop's country preview uses.
  - **The desktop.** On the core route, `python3 -m goal2.desktop --core-boot <date-call state> --data <GOAL.DAT>` opens Launch, whose **New career** runs the original's new game:
    - the country list and preview read from the core;
    - the manager name;
    - the bulletins, shown as goal2 pages with the original's text read from memory;
    - then the main window from T105.

    The start year is offered as today's Launch does (1990 or 1992). The core answers the DOS year that the original turns into it (start − 1, by NG-9), and the review page names the year and stage the original then set.

- **Hazards**:
  - Never hook INT 21h with a plain Unicorn interrupt hook alone. The `Intr` path enters by `retf` (F032).
  - Never write the year, the seed or any byte into memory. The DOS time is an input to the interrupt, nothing more.
  - `GOAL.DAT` is read at run time from the player's path, and no byte of it enters the repository.
