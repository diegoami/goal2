# The assumption register

Every rule the rebuild plays by, and where it comes from. [`plan.md`](plan.md) says how it is used.

**Source tags**
- `finding`: a goal2-archaeology finding (F-number). F022–F029 are `proposed` at the T39 source pin
  below; a vendored model is also held to its own seed-exact check.
- `owner`: the owner's answer (goal2-archaeology `experiments/E015-human-playthrough/owner-questions-2026-10-11.md`, or an issue here).
- `help file`: GOAL.HLP, quoted in goal2-archaeology `sources/goal-hlp.md` (passage `P<nn>`). It is
  the game's documentation, not its code: it loses to a finding.
- A run record cited without a finding says so; it counts like `finding` until one is written.
- `assumed`: our guess. Each one says why, and what replaces it (a goal2-archaeology question or
  milestone).

A row changes in the PR that changes its rule. Its **Live** column names an implementation that
exists in this repository; a phase marker means planned work and is not executable behavior.
The campaign rows reconciled in T39 use goal2-archaeology findings F022–F029 as pinned at
`0ef880e1f6ec9bc12b3f12c3aaecb4d747d9d5cb`. These findings remain **proposed**. A static reading
of the listing, a Unicorn run of original bytes, a measured run or replay count, and an owner
decision are distinct evidence; a measured stand-in is not a run of an original campaign fixture.
