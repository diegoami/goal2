not an implemented interface. Open [the interactive study](index.html) locally;

shirt symbols are newly authored geometry. The prototype runs without network access. Its tactic wording records the audit

use a scoreboard and a readable event list. This is a proposed composition for
ordinary PySide6 widgets, not an embedded browser or toolkit migration.
