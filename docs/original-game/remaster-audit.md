## Actionable backlog and boundaries

1. **Existing**, not refiled: [#241](https://github.com/diegoami/goal2/issues/241) roster browsing, [#242](https://github.com/diegoami/goal2/issues/242) complete player attributes, [#243](https://github.com/diegoami/goal2/issues/243) match entry/speed, [#198](https://github.com/diegoami/goal2/issues/198) match presentation. Their accepted contracts take priority where they touch the same UI. [confirmed: linked issue contracts]
2. **[#248](https://github.com/diegoami/goal2/issues/248): management decisions** — position/formation, personal tactics and opponent marking, with safe preview/draft semantics and known engine support only. [designed: audit row 4]
3. **[#249](https://github.com/diegoami/goal2/issues/249): campaign context** — browsable fixtures/results/group opponents, rankings, history and bulletin context for the next decision, without changing competition rules. [designed: audit rows 2 and 5]
4. **[#250](https://github.com/diegoami/goal2/issues/250): watched-match decisions** — define which original prompts/actions can be exposed safely through the existing worker before implementing controls; visual styling #198 is a separate slice. [designed: audit row 7]
5. **[#251](https://github.com/diegoami/goal2/issues/251): retrospective results** — history and saved summary/replay discovery, beginning with read-only available result data; never invent a replay if no durable event recording exists. [designed: audit row 8]

For each new slice, the primary action should be visible next to the information it uses. Keyboard focus, mouse access, table scrolling and small-window reachability belong in acceptance, while original observations and future design stay separately cited. [designed: owner #244]
