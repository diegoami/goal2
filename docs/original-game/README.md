# Original GOAL2: illustrated play and interface reference

This private reference records what the 1993 game displayed and how its player moved between decisions. The [first-session walkthrough](first-session.md) is the illustrated sample; the [screen inventory](screen-inventory.md) links every currently classified E015 screen kind, and [image provenance](image-provenance.tsv) contains each source state and full hash. [confirmed: E015 screen catalogue; E031 play guide]

The pictures are original-game screens reconstructed from retained DOSBox-X states, with the source savestate checked against the E015 evidence manifest before rendering. These states came from several separate sittings. A picture beside a step demonstrates that screen and its information; it does not claim all pictures are a single uninterrupted playthrough. The renderer uses the original VGA font from each state and a fixed 8-pixel cell width, so some box borders and glyphs can look narrower than DOSBox-X's 9-pixel text display. [confirmed: archaeology `docs/screens.md`, `tools/screens/render.py`]

Evidence notation in this guide: `E015-rNNNN state S` is a retained screen and hash-verified state; `E031 Cnn` refers to a row in the [observed-claims register](https://github.com/diegoami/goal2-archaeology/blob/main/experiments/E031-play-the-game/out/claims.md) with its exact logged step. A screen's printed hint proves the hint was displayed. E031 controls are cited only where its logged single-step action supports them. Multi-key E015 bursts are observations of before and after states, not proof that one key caused the transition. `[designed]` marks a recommendation for the remaster. [confirmed: archaeology `docs/screens.md`, E031 `claims.md`]

The current image set is an initial coverage baseline, not the final manual: the E015 classifier has 29 kinds, including the DOS prompt and file-error prompt. Their authentic renders are present in the inventory. More states and unclassified squad, pool, competition, replay and campaign screens will be added next, alongside the complete flow and goal2 comparison. [confirmed: `static/screens/kinds.tsv`, `catalogue.tsv`; E031 play guide]
