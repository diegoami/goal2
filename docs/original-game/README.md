# Original GOAL2: illustrated play and interface reference

This reference records what the 1993 game displayed and how its player moved between decisions. Start with the [illustrated first session](first-session.md), then follow [squad and tactics](squad-and-tactics.md), [fixtures and campaign](competition-and-campaign.md), [a match and results](match-and-results.md), and [start, save and replay](startup-save-replay.md). The [connected flow](flow.md), [screen inventory](screen-inventory.md) and [remaster audit](remaster-audit.md) are quick reference; [coverage](coverage.md) names the remaining evidence gaps. [confirmed: E015 screen catalogue; E031 play guide; M244 captures]

The pictures are original-game screens reconstructed from retained DOSBox-X states. E015 source states were checked against the evidence manifest before rendering. New M244 images come from a one-key-per-step headless original-game run loaded from a hash-verified published G1A save; see the [capture method](capture-method.md), [per-step logs](captures/) and [image provenance](image-provenance.tsv). These pictures come from separate sessions and do not imply one uninterrupted playthrough. The renderer uses the original VGA font with an 8-pixel cell width, so some box borders and glyphs look narrower than DOSBox-X's 9-pixel text display. [confirmed: archaeology `docs/screens.md`, `tools/screens/render.py`; M244 capture logs]

Evidence notation: `E015-rNNNN state S` identifies a retained screen and hash-verified state; `E031 Cnn` identifies an entry in the [observed-claims register](https://github.com/diegoami/goal2-archaeology/blob/main/experiments/E031-play-the-game/out/claims.md) with its logged step; `M244-G1A-NN step S` identifies a newly captured single action and before/after digest. A printed hint establishes that the hint appeared, not that every branch follows it. Multi-key bursts cannot prove single-key causality. `[designed]` marks a remaster recommendation; the original DOS layout is evidence of information and flow, not a UI template.
