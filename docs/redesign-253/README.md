# GOAL2 whole-game plan: parity, queue and gaps (#253)

[designed: owner, 2026-10-20] **The direction is chosen.** The owner accepted [vision #266 / PR #267](https://github.com/diegoami/goal2/issues/266#issuecomment-6287825622): an installable desktop game that looks like the original GOAL2, with black screens, strong varied colors, large text, complete graphical attribute bars, a maximum-size pitch, default-hidden full commentary (latest two lines visible) and independently retractable top and side bars. This package no longer recommends a visual direction. It holds the evidence that makes the accepted vision buildable without silently losing original information: the 234-source parity inventory, the capability boundaries, the current-build audit, the approved queue and the open owner choices. The earlier “A — Country desk” paper/ink/emerald recommendation is superseded and kept only as reviewed history.

[designed: first supported session] The first release is deliberately smaller than full parity: launch or Resume → safe new career → shell and complete Team/pool comparison → confirmed supported friendly → Quick or view-only Watch → explained result → next fixture → Save and Resume ([lanes 2–3](vision-reconciliation.md#approved-queue)). Complete cards depend on [#242](https://github.com/diegoami/goal2/issues/242), prominent Play/Watch and frozen speed on [#243](https://github.com/diegoami/goal2/issues/243); neither is claimed present on main. Roles reuse [#248](https://github.com/diegoami/goal2/issues/248); #249, #250 and #251 supply only their bounded available-information, supported-decision and retained-record work. Watch flags and other Watch modes, in-flight quick continuation, friendly rearrangement, generated bulletins, complete profiles and records, durable replay and export, assistant and identity delivery and local managers have **no delivery owner** today: they need bounded contracts before any full-parity claim ([scope gaps](vision-reconciliation.md#scope-gaps-and-their-owners)). A placeholder or contract alone is not parity.
