[designed: #253] The design keeps country identity, opponent comparison, dense player cards, explicit tactical choices, readable live feedback, football typography and a newspaper-like bulletin. It changes the hidden function-key architecture, context-dependent Enter actions, transient prompts and separated data views. A modern game should reveal its current state and next action without source-code knowledge. The DOS composition is inspiration and evidence, not a layout mandate.
