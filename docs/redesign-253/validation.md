# Planning validation and limits

[designed: #253] These checks validate a reviewable planning package. They do not accept a future UI, establish performance/usability, decide unknown original meanings or authorize implementation. [validate.py](validate.py) uses stdlib plus read-only Git commands and supports `--root /absolute/checkout`, so a main-owned frozen copy can check the reviewed tree. No reviewer harness or shared permission file is changed here.

## Rework round 3 (same-reviewer follow-up at 392b32c)

[designed: #253 rework] Round 2's tables fixed direction but its parser stopped at the first row that differed from an exact spacing pattern (R4: an extra row `| #242 | #198 | lane 2|` was silently dropped, in both tables of all three files) and exempted every line starting `| #` from the contradiction scan (R5: `| #242 must precede #198 |` or `| #251 → #262 |` in another table passed). Class fix: a table has the extent GFM gives it, the header line and every following line up to a blank line or another block start (a line without pipes directly after the last row is still a row of the table); every row is split on pipes with whitespace ignored, must begin and end with a pipe and must have the header's cell count; the canonical tables must parse completely, every row accounted for, and equal the oracle; only the lines of the two canonical blocks, identified by position, are exempt from the contradiction scan, and every other line, other tables' cells included, is scanned. Sweep of `validate.py` for regex-anchored row parsers, loops that end on an unexpected line, and prefix or blanket exemptions (each now parses its whole table, fails on an unparsed row and refuses a duplicate key):

| Site | Before | Now |
| --- | --- | --- |
| `parse_pairs` (queue tables) | `while` loop ended at the first row not matching an exact-spacing regex | `canonical_table`: whole block, every row parsed or failed by name |
| `queue_dependencies` contradiction scan | dropped every line starting `| #` and every line equal to a lane row | only the canonical block lines, by position, are exempt |
| lane rows | regex `^\| \d[a-e]?` plus a pipe count | table rows whose first cell is a lane number |
| canonical headers | exact string equality, so a compact copy was not counted | cells compared, exactly one block |
| parity matrices (`parity/*.md`) | `re.findall` of allocation rows, other rows skipped | whole tables; a non-allocation row fails |
| `journeys.md` S-table | `re.findall`, other rows skipped | `keyed_rows` |
| `backlog.md` child lane/priority table | `re.findall` into a dict, the last duplicate won | `keyed_rows`, duplicates fail |
| `decision_rows` | first-cell regex into a dict, the last duplicate won | `keyed_rows`, duplicates fail |
