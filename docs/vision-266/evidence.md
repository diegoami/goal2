## Validation and provenance

[designed] New SVG/PNG screens are authored locally with `render.py`, DejaVu Sans and primitives; no original assets, savestates, executables, screenshots or game data are added. `scenario.json` supplies the shared illustrative roster/events. `python3 docs/vision-266/render.py --check` checks roster transitions, event/score consistency, all card categories and measured text bounds, and checks that retained SVG/PNG bytes match regeneration. The authoring utility imports no game module, accepts no game input and executes no game behavior. Pillow and Inkscape are authoring dependencies only, not product dependencies.

[designed] Use `python3 tools/check_links.py` and `git diff --check` for repository documentation checks. Required clean-head premerge checks and independent documentation review remain separate.
