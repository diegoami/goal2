# Bundled fonts

[designed: #278] DejaVu Sans Mono, regular and bold, version 2.37 (Debian `fonts-dejavu-core`
2.37-8). The desktop and the pitch view use it on every platform, because Windows has no DejaVu
Sans Mono and its fallbacks have other metrics and lack the pitch marks. The licence is in
[LICENSE](LICENSE) (Bitstream Vera; free to use and redistribute). This is not an original-game asset.
